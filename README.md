# Alox Beauty

Final promotional video for Alox Beauty.

## The video

[`alox-beauty.mp4`](alox-beauty.mp4) — 1:57, portrait (626×1128, 9:16), H.264 + AAC.

Click the file above to play it in GitHub's viewer. It is encoded for web playback:
H.264 baseline-compatible video so it plays in every current browser, and with the
`moov` atom at the front of the file so it starts immediately instead of buffering
the whole download first.

## Source master

The full-resolution master (HEVC, ~227 MB) is **not** in this repository. It lives in
the shared Dropbox folder alongside the rest of the project assets. The copy here is a
web-encoded derivative intended for viewing and sharing, not for re-editing — start
from the Dropbox master for any further work.
